06 / SECURITY BY DEFAULT
安全不是最后补丁。
而是第一步。
AI 自动化的每一步都应保留人类审批权。尤其是有权限修改代码、运行终端、访问浏览器和发布线上内容时。
查看 Google 官方权限设置 ↗
01最小授权
只允许当前目录；高风险命令与外部发布人工确认。
02先有回滚
每个重要阶段提交 Git，能恢复才敢加速。
03秘密不出库
不提交 API Token、.env、真实客户数据和凭据。
04测试才算完成
截图、测试日志、线上访问都要真实复核。
