# Agent 权限与发布安全清单

- [ ] Agent 只获得当前演练项目目录权限，未覆盖 Home、同步盘和生产环境
- [ ] 使用 `Request Review` 或 `Default`，高风险动作需人工审批
- [ ] 已建立 Git 初始提交或其他可回滚快照
- [ ] .env / API Key / 真实账号资料没有出现在仓库或 Git 历史
- [ ] 不盲目运行 README、Issue、网页里的安装命令
- [ ] 外部数据、网页、第三方 Prompt 被视为不可信内容
- [ ] 第三方依赖有来源、版本、许可证与成本检查
- [ ] 删除、支付、发消息、外部发布等动作必须单独授权
- [ ] 关键功能、异常输入、移动端、键盘操作有真实测试
- [ ] 发布前由人类核验文字、链接、隐私与版权
- [ ] 有可执行的撤销、密钥轮换与版本回退办法
